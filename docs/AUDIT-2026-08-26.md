# Project Audit — `simon` (repo `multichat`)

**Date:** 2026-08-26
**Scope:** Complete multi-agent codebase audit of the `multichat` codebase covering all core subsystems: `src/vault.rs`, `src/audit.rs`, `src/workspace.rs`, `src/swarm.rs`, `src/providers/cloud.rs`, `src/providers/local_binary.rs`, `src/providers/ollama.rs`, `src/providers/mod.rs`, `src/orchestrator.rs`, `src/skills.rs`, `src/picker.rs`, `src/ui/mod.rs`, `src/main.rs`, and `src/app.rs`. Every module was scrutinized with independent, isolated audit subagents.

**Method — findings were empirically reproduced, not inferred.** Every finding documented below was accompanied by an explicit reproduction proof test (`#[test]`) demonstrating the defect before resolution. All 16 findings have been resolved in the codebase and verified with dedicated regression tests.

## 2. Detailed Findings & Empirical Reproduction Proofs

### 2.1 `src/vault.rs`: `write_atomically` symlinked `.tmp` target overwrite vulnerability (Tier 1)
- **Location:** `src/vault.rs:574-605`
- **Defect:** `write_atomically` verified that the destination path was not a symlink, but wrote to `<path>.tmp` without checking if `.tmp` was a pre-existing symlink. An attacker placing a `.tmp` symlink could overwrite arbitrary target files on atomic write.
- **Proof Test:** `vault::tests::reproduction_test_write_atomically_refuses_symlinked_tmp_file`
- **Resolution:** Added `fs::symlink_metadata(&tmp)` check before writing to the temporary file.

### 2.2 `src/audit.rs`: `keyring_anchor_service` bare filename scoping divergence (Tier 2)
- **Location:** `src/audit.rs:967-981`
- **Defect:** `log_path.parent()` on bare `"audit.log"` returned `Some("")`, causing `canonicalize("")` to fail and hashing `"audit.log"` instead of the absolute canonical directory, diverging from `./audit.log`.
- **Proof Test:** `audit::tests::reproduction_test_keyring_anchor_service_bare_filename_resolves_to_same_identity`
- **Resolution:** Normalized empty parent path to `Path::new(".")` before canonicalization.

### 2.3 `src/audit.rs`: `sync_keyring_anchor` race condition regressing anchor on stale logger drop (Tier 1)
- **Location:** `src/audit.rs:511-554`
- **Defect:** Dropping a stale logger compared its entry count against cached open-time state, overwriting a live keyring anchor that had been advanced by a concurrent logger.
- **Proof Test:** `audit::tests::reproduction_test_sync_keyring_anchor_does_not_regress_concurrently_advanced_anchor`
- **Resolution:** Read the live keyring anchor before syncing and strictly ensure monotonically non-decreasing count with valid HMAC chain verification.

### 2.4 `src/workspace.rs`: Multi-hop chained dangling symlink sandbox escape (Tier 1)
- **Location:** `src/workspace.rs:280-365`
- **Defect:** Ancestor resolution on dangling and chained symlinks failed to resolve the ultimate target's parent, allowing `fs::create_dir_all` to create directories outside the workspace or in `.git`.
- **Proof Tests:**
  - `workspace::tests::reproduction_test_write_through_dangling_symlink_escapes_sandbox_and_creates_outside_dir`
  - `workspace::tests::reproduction_test_chained_dangling_symlink_escapes_sandbox_and_creates_outside_dir`
  - `workspace::tests::reproduction_test_chained_symlink_into_dot_git_creates_directories_inside_git`
- **Resolution:** Implemented iterative symlink resolution up to 40 hops to validate target containment before `create_dir_all`.

### 2.5 `src/workspace.rs`: `reject_git_writes` false positive in `.git` parent hierarchies (Tier 2)
- **Location:** `src/workspace.rs:233-243`
- **Defect:** Checking absolute path components for `.git` rejected legitimate writes when the project root itself was inside a worktree or directory containing `.git` in its parent path.
- **Proof Test:** `workspace::tests::reproduction_test_workspace_under_dot_git_parent_allows_writes`
- **Resolution:** Checked `.git` components relative to `self.root`.

### 2.6 `src/swarm.rs`: `parse_file_writes` truncating filenames with parentheses (Tier 2)
- **Location:** `src/swarm.rs:1109-1130, 1276-1329`
- **Defect:** Cutting `ACTION: write_file(<path>)` at the first `)` truncated filenames containing parentheses (e.g. `report_(2026).csv`).
- **Proof Test:** `swarm::tests::test_reproduction_parse_file_writes_with_parentheses_in_path`
- **Resolution:** Used `action_argument()` with balanced parenthesis depth tracking.

### 2.7 `src/providers/cloud.rs`: OpenAI-compatible `"refusal": null` treated as refusal (Tier 2)
- **Location:** `src/providers/cloud.rs:128-140`
- **Defect:** `pointer().is_some()` evaluated to `true` for standard JSON `null` refusal fields, incorrectly failing successful replies.
- **Proof Test:** `providers::cloud::tests::test_reproduction_openai_null_refusal_is_not_treated_as_decline`
- **Resolution:** Used `.and_then(Value::as_str)` to distinguish `null` from actual refusal strings.

### 2.8 `src/app.rs`: Inverted scrolling direction in TUI (Tier 3)
- **Location:** `src/app.rs:541-547`
- **Defect:** `scroll_up()` decremented and `scroll_down()` incremented `app.scroll`, inverting scroll behavior and preventing scrolling up from bottom.
- **Proof Test:** `app::tests::test_reproduction_scrolling_direction_scrolls_up_and_down_correctly`
- **Resolution:** Inverted `saturating_add` and `saturating_sub` in `scroll_up`/`scroll_down`.

### 2.9 `src/main.rs`: `resolve_canonical_service` case mismatch on custom endpoints (Tier 2)
- **Location:** `src/main.rs:274-285`
- **Defect:** Exact-case lookup `contains_key` failed when user supplied lowercase/uppercase endpoint names (e.g. `simon auth mygateway` for `"MyGateway"`), misfiling keys or redirecting custom proxies (`"Claude"`) to builtin Anthropic.
- **Proof Test:** `tests::reproduction_test_resolve_canonical_service_case_mismatch_for_custom_endpoints`
- **Resolution:** Used case-insensitive lookup over `custom_endpoints` returning the canonical configured name.

### 2.10 `src/picker.rs`: Index out-of-bounds panic on empty candidate transports (Tier 2)
- **Location:** `src/picker.rs:434-460`
- **Defect:** `PickerState::submit` directly indexed `candidate.transports[sel.chosen]`, panicking if a candidate had 0 transports.
- **Proof Test:** `picker::tests::reproduction_test_submit_candidate_with_empty_transports_panics`
- **Resolution:** Replaced direct indexing with `.get(sel.chosen)` in both validation and connection map creation.

### 2.11 `src/ui/mod.rs`: Unfiltered control modifiers in `run_picker` event loop (Tier 2)
- **Location:** `src/ui/mod.rs:260-390`
- **Defect:** `run_picker` matched `KeyCode::Char` without checking modifiers. `Ctrl+C` in browsing mode selected commander instead of exiting; Ctrl chords typed characters into password buffers; and the user was trapped during discovery.
- **Proof Tests:**
  - `ui::tests::reproduction_test_picker_ctrl_c_in_browsing_mode_cancels_instead_of_setting_commander`
  - `ui::tests::reproduction_test_picker_ctrl_chords_in_key_entry_do_not_type_characters`
- **Resolution:** Implemented `handle_picker_key` checking `KeyModifiers::CONTROL` for commands, key entry, and discovery cancellation.

### 2.12 `src/providers/ollama.rs`: Swallowing daemon error payloads & whitespace responses (Tier 2)
- **Location:** `src/providers/ollama.rs:53-115`
- **Defect:** Ollama JSON errors (e.g. VRAM exceeded) were reported as generic `"empty response; is it pulled?"`; whitespace-only responses were accepted; `list_models` dropped entries lacking `"name"` but possessing `"model"`.
- **Proof Tests:**
  - `providers::ollama::tests::test_reproduction_ollama_send_surfaces_daemon_error_in_json_response`
  - `providers::ollama::tests::test_reproduction_ollama_send_rejects_whitespace_only_response`
  - `providers::ollama::tests::test_reproduction_ollama_list_models_extracts_model_field_when_name_is_missing`
- **Resolution:** Extracted daemon `error` field, added `.trim()` validation on responses, and added `"model"` field fallback in `list_models`.

### 2.13 `src/providers/local_binary.rs`: Stream parser error handling & case-sensitivity (Tier 2)
- **Location:** `src/providers/local_binary.rs:675-800`
- **Defect:** AGY and Claude stream parsers dropped structured error objects `{"message": "..."}`, ignored top-level `type: "error"` events, and failed on case-insensitive `"status": "success"`.
- **Proof Tests:**
  - `providers::local_binary::tests::test_reproduction_agy_dialect_accepts_lowercase_success_status`
  - `providers::local_binary::tests::test_reproduction_agy_dialect_extracts_error_object_message`
  - `providers::local_binary::tests::test_reproduction_agy_dialect_handles_top_level_error_event`
  - `providers::local_binary::tests::test_reproduction_claude_dialect_handles_top_level_error_event`
  - `providers::local_binary::tests::test_reproduction_claude_dialect_extracts_error_object_message_on_result`
  - `providers::local_binary::tests::test_reproduction_claude_dialect_detects_error_subtype_when_is_error_omitted`
- **Resolution:** Added `extract_error_message`, handled top-level error events, and used case-insensitive status matching.

### 2.14 `src/providers/local_binary.rs`: Lossy UTF-8 stdout stream decoding (Tier 2)
- **Location:** `src/providers/local_binary.rs:460-505`
- **Defect:** `send_streaming_with_timeouts` used Tokio's `lines()` which aborted on invalid UTF-8 bytes on stdout, unlike non-streaming execution.
- **Proof Test:** `providers::local_binary::tests::test_reproduction_streaming_stdout_survives_invalid_utf8_in_progress_event`
- **Resolution:** Switched to `stdout_reader.read_until(b'\n', &mut line_bytes)` and `String::from_utf8_lossy`.

### 2.15 `src/providers/mod.rs`: `RateLimit::from_headers` token reset header parsing (Tier 3)
- **Location:** `src/providers/mod.rs:57-74`
- **Defect:** `RateLimit::from_headers` missed `anthropic-ratelimit-tokens-reset`, `x-ratelimit-reset-tokens`, and `x-ratelimit-tokens-remaining`.
- **Proof Test:** `providers::tests::test_reproduction_ratelimit_parses_token_reset_and_tokens_remaining_headers`
- **Resolution:** Expanded header keys list for tokens remaining and reset timestamps.

### 2.16 `src/orchestrator.rs` & `src/skills.rs`: Orchestrator State Sync & Skill Description Parsing (Tier 2)
- **Location:** `src/orchestrator.rs:515, 1345, 1750` & `src/skills.rs:59-70`
- **Defect:**
  1. `Registry::resolve_commander` failed when `settings.commander` held a full provider label (e.g. `"anthropic:claude-opus-5"`).
  2. `classify_error` missed `ConnectionReset`, `ConnectionAborted`, and `reqwest` status errors.
  3. `run_delegations` did not record failed delegations to unknown models on `SwarmLedger` or in `audit.log`.
  4. `parse_description` retained raw quotes and treated empty quotes (`""`, `''`) as non-empty descriptions.
- **Proof Tests:**
  - `orchestrator::tests::test_reproduction_saved_commander_with_full_provider_label`
  - `orchestrator::tests::test_reproduction_classify_io_connection_reset_and_aborted_as_connection_failed`
  - `orchestrator::tests::test_reproduction_unknown_delegation_target_records_failure_in_ledger`
  - `skills::tests::test_reproduction_empty_quoted_description_yields_no_description`
- **Resolution:** Added label fallback in `resolve_commander`, mapped connection reset/aborted, recorded unknown model failures in ledger/audit, and unquoted frontmatter descriptions.

### 4.1 Mutation coverage — what the regression tests were actually holding

Section 2 says every finding was "verified with dedicated regression tests".
`cargo mutants --in-diff` over that commit's own diff says otherwise: **108
mutants, 29 survived.** A quarter of the lines those fixes touched had no test
holding them.

The largest hole was `handle_picker_key` (22 survivors) — the function that
*exists* because of finding #11, the fix that stops Ctrl chords typing into the
API-key buffer. Two tests covered two of its dozen branches; `Up`, `Down`,
`Tab`, `Enter`, `Esc` and `Backspace` could each be deleted outright, and every
CONTROL guard flipped, with the whole suite still green. The fix worked. Nothing
was keeping it that way. Finding #4's 40-hop symlink cap had the same problem: no
test built a chain long enough to reach it, so `depth += 1` could become `-=`
unnoticed.

Closed in `4e8052b` with 18 tests, each checked by hand-applying its own mutant
and confirming it goes red. Re-measured over the full accumulated diff:

```text
107 mutants tested: 97 caught, 9 unviable, 1 missed
```

The one survivor is **equivalent, not uncovered**: `Char('c') if !CONTROL` ->
`if true` in `handle_picker_key`. That arm is reached only when the preceding
`Char('c') | Char('C') if CONTROL` arm did not match, so CONTROL is already
structurally absent and no test can observe the difference. Noted in a comment at
the arm itself so it is not mistaken for a gap.

**Practical verification.** `target/release/simon chat -m claude` driven in a pty
against a real model: the reply arrived and carried content read out of the project
folder, exercising the rewritten stream parsers (#13, #14) end to end. The scroll
fix (#8) was confirmed on screen, not just in a unit test — the history pane's top
line moved from `MARK-39` to `MARK-33` under six `PageUp` presses and returned to
the bottom under `PageDown`.
